# Accuracy scenarios

Does the city ranking point where real players are? We compare it with Google Trends interest by country for a *real shipped game* like each hypothetical one, and with two baselines: an LLM given the same inputs but no Qloo data, and plain gamer popularity. Scripts: `apps/api/scripts/scenarios.py`, `llm_baseline.py`, `fetch_trends_truth.py`. Numbers on this page are generated by `scenarios.py score`.

**Method.** Each scenario is a hypothetical game with its own comps and, when the game has a setting, culture anchors (films, shows, artists) resolved through Qloo search. Each truth game is never used as a comp and is removed, with the rest of its series, from the expanded signal. Every candidate city is scored; country score = mean of its cities. Truth = Google Trends interest for the analogue (last 5 years), restricted to candidate countries. ρ = Spearman over candidate countries with Trends data (needs ≥ 5).

## 3. Baselines

- **LLM only**: an LLM given the same inputs (description, comps, culture anchors, platforms, candidate countries), no Qloo data, temperature 0, asked to rank the countries where such players most over-index. Prompt and code: `apps/api/scripts/llm_baseline.py`.
- **Popularity**: all gamers alone (mean of the PC, mobile, console panels): no game signal at all. It shows how much of each ranking is just "where gamers are".

## Caveats

- Google Trends measures search interest share per country, not downloads, wishlists or sales.
- Truth is country level; cities within a country are averaged. The app itself ranks cities.
- Candidate countries are the app's markets with Qloo data, so places like Russia, Pakistan or Romania that top some Trends lists are outside every ranking.
- Small samples: 10 tuning games and the held-out games above. One miss moves a hit rate by several points.
- Each LLM ran once, at temperature 0, on one prompt. Another model or prompt could do better or worse.
